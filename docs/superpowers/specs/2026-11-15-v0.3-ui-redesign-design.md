# Claude Hub v0.3.0 UI 架构升级设计规格（融合 Copilot Speedometer 设计体系）

## 1. 背景与目标

`v0.2.x` 系列的 Claude Hub 采用纵向堆叠的 4 个圆角手风琴卡片（监控、会话历史、扩展与记忆、高级配置）、带 7 个 Emoji 图标的顶栏以及固定段落式的状态栏悬停卡片。随着功能演进（Auto Memory、Loop、后台 `/tasks`、输出速率、协作代理拓扑），窄侧边栏中出现了纵向滚动过长、视觉噪音偏高以及协作代理卡片横向溢出（见 `Bug.md`）等问题。

`v0.3.0` 参考 `copilot-speedometer` 的克制原生视觉与工程结构，达成以下四个可验证目标：

1. **版本分支清晰隔离**：在现有 `v0.2.26` 提交点锚定 `release/v0.2.x` 维护分支，主线进入 `v0.3.0` 迭代。
2. **左侧栏 + 编辑器宽屏双宿主四分栏**：采用吸顶单行四分栏（`监控 / 会话 / 扩展 / 设置`）+ 右侧纯 SVG 图标（`刷新` + `在编辑器标签页打开`），窄栏单列、宽屏双栏（Master-Detail）自适应，并彻底修复协作代理拓扑溢出。
3. **右下角状态栏与悬浮窗双风格 + 深度自定义**：新增 `claudeHub.statusBar.style`（默认 `modern` 表格对齐风，可一键切回 `classic` 0.2 经典 Claude Hub 风），支持底栏 10 项字段组合、5 档预设（新增 `speed` 速率优先）与悬浮窗 9 大区块独立开关，并在左侧「设置」Tab 内置可视化实时配置面板。
4. **模块化拆分 Webview 与纯函数悬停构建器**：将 5100+ 行的 `src/webviewHtml.ts` 拆分为职责单一的子模块，保持对外 `getWebviewContent()` 契约兼容与中英双语键值对称。

## 2. 版本与分支管理策略

- **0.2.x 维护线**：基于当前 `v0.2.26` 提交（`12fc5d5`）建立 `release/v0.2.x` 分支，保留完整 `0.2.x` 界面与打包链路，供需要旧版独立 VSIX 的场景随时检出构建。
- **0.3.x 开发线**：在独立特性分支 `feat/v0.3-ui-redesign` 上完成本次重构与测试验证，合入主线后版本号升至 `0.3.0`。
- **静态预览能力**：新增 `scripts/preview.mjs`（及 `npm run preview`），无需启动 VS Code 即可将新版 Webview（窄栏 340px 与宽屏双栏、中文与英文）输出为本地预览 HTML，同时把 `.superpowers/` 与预览临时输出目录加入 `.gitignore`。

## 4. 左侧栏与编辑器宽屏视图（Webview）规格

### 4.1 顶栏与全局动作归位

- **顶栏（Sticky Header）**：
  - 左侧：品牌星标 SVG + `Claude Hub`（在 `body.narrow` 下隐藏文字，释放宽度给 4 个等宽 Tab）。
  - 中部：`监控`（`monitor`）、`会话`（`sessions`）、`扩展`（`extensions`）、`设置`（`settings`）四个单行底边高亮 Tab。
  - 右侧：仅保留 `刷新`（SVG）与 `在编辑器标签页打开`（SVG；当前已在编辑器标签页时自动隐藏）。
- **原顶栏其余 5 个动作按场景就近归位**：
  - `工作区 / 全部` 过滤：置于「监控」与「会话」Tab 顶部的 `.segmented` 分段开关。
  - `/ 斜杠命令`、`后台任务 (/tasks)`（带运行数角标）、`工作区成本报告`：置于「监控」Tab 中部的轻量幽灵按钮行。
  - `全文搜索会话记录`、`新建 Worktree 会话`：置于「会话」Tab 搜索框右侧。

### 4.2 Tab 1：监控（Monitor）

1. **范围工具栏**：左侧 `本窗口 / 全部` 分段开关，右侧显示聚焦项目名与运行态圆点（活跃时绿色呼吸圆点，空闲时半透明圆点）。
2. **Hero 主卡片**：
   - 左边框 `3px solid var(--blue)` 强调。
   - 顶行：模型与 `effort` 标签（如 `OPUS 5.5 · HIGH`）+ 相对活跃时间。
   - 主数值行：大字号上下文百分比 + 已用/上限 Token（如 `42%  84.0k / 200k`），右侧并列显示最近响应输出速率（如 `58.4 tok/s`；终端采集未启用时提供紧凑启用按钮）。
   - 进度条：`5px` 主题色平滑进度条。
   - 底行：Git 分支名 + 5h 订阅配额（仅在启用或存在配额数据时展示）。
3. **自适应 KPI 网格**（宽屏 4 列，`body.narrow` 下 2×2 网格，`font-variant-numeric: tabular-nums`）：
   - 会话预估费用（含子代理额外 Token 副标题）
   - 缓存读取 Token 与命中率（副标题显示缓存写入 Token）
   - 输入 / 输出 Token 明细
   - 会话运行时长（副标题显示总跨度）
4. **实时活动横幅**：
   - 工具执行中显示细线圆环 Spinner + 工具名 + 单行截断目标路径/命令 + 耗时胶囊。
   - Loop 激活时显示 Loop 模式、间隔与下次唤醒倒计时横幅。
5. **原生通栏分组（`.block-head`）**：
   - **会话待办任务**：贴边通栏折叠头 + 完成进度计数胶囊；完整保留现有 `Task / Checklist` 模式标签、任务列表绑定选择、复制同步提示词、清除隐藏已完成项以及展开/收起长描述能力。
   - **协作代理拓扑（修复 `Bug.md` 横向溢出）**：
     - `.agent-item` 强制 `min-width: 0; max-width: 100%; overflow: hidden`。
     - 嵌套子代理 `.agent-item.nested` 使用 `margin-left: 12px; border-left: 2px solid var(--blue)`，移除原先越界的 `left: -10px` 绝对定位伪元素。
     - 标题行 `.agent-name` 设置 `flex: 1; min-width: 0; overflow: hidden; text-overflow: ellipsis; white-space: nowrap`。
     - 元数据行 `.agent-badges` 允许 `flex-wrap: wrap`，内部每个 `.agent-meta-chip`（含超长 `worktree` 分支名）设置 `max-width: 100%; overflow: hidden; text-overflow: ellipsis; white-space: nowrap`，描述区设置 `overflow-wrap: anywhere`，确保在 220px 极窄侧栏下零横向溢出。
   - **后台任务 (`/tasks`)**：存在运行中或近期后台任务时展示通栏分组与打开入口。

### 4.3 Tab 2：会话（Sessions）

- **工具栏**：第一行 `搜索框` + `全文搜` + `+ Worktree`；第二行 `全部 / 本窗口 / 置顶 / 活跃` 分段筛选 + 会话总数。
- **时间分组**：按 `活跃中 / 今天 / 昨天 / 本周 / 更早`（置顶会话优先置顶分组）组织卡片，消除卡片底部的密集按钮堆砌。
- **宽窄自适应主从交互**：
  - **宽屏（编辑器标签页或宽度 `>= 600px`）**：左列（`310px`）常驻会话列表，右列常驻选中会话的阅读器详情面板。
  - **窄栏（`body.narrow`）**：默认处于 `mode-list` 单列列表态（无嵌套滚动条，随页面自然滚动）；点击任意会话卡片切换至 `mode-detail` 详情态并记录列表滚动高度，顶部提供 `← 返回会话列表` 按钮恢复原滚动位置。
- **会话详情阅读器**：
  - 标题、状态徽章（运行中 / 当前聚焦 / 置顶 / 分叉 / 子代理数）与 `<dl class="kv">` 元数据表（项目、路径、分支、模型、上下文、费用、标签）。
  - 主操作按钮网格：`终端恢复`、`聚焦监控`、`分叉会话`、`打开 JSONL`、`时间线`（若存在分叉来源则含 `对比分叉`；若存在 Worktree 则含 `打开 Worktree`）。
  - 次级管理链接行：`重命名`、`编辑标签`、`置顶/取消置顶`、`导出 Markdown`、`新会话交接`、`删除记录`（危险红色）。

### 4.4 Tab 3：扩展（Extensions）

- 顶部保留实时搜索框与 `全部 / 记忆 / MCP / 技能 / 插件 / 代理` 分段过滤及数量提示。
- 各分类统一采用 `.block-head` 原生通栏折叠头；MCP 服务器与已安装插件的启用开关统一升级为无障碍圆角拨动 `.switch`（`role="switch"` + `aria-checked`）。
- 完整保留项目记忆（Auto Memory）的 `MEMORY.md` 打开、索引同步、内联新建/编辑表单（4 种类型胶囊）与顶部向导入口，以及技能的 `全部 / 本地 / 插件` 范围筛选。

### 4.5 Tab 4：设置（Settings）

在 Webview 内直接提供可视化配置工作台（修改后即时通过宿主写入 VS Code `Configuration` 并实时刷新右下角）：

1. **右下角状态栏与悬浮窗定制区**：
   - **整体风格分段开关**：`Modern（0.3 表格对齐）` / `Classic（0.2 经典 Claude Hub）`，默认值 `modern`。
   - **底栏预设分段开关**：`极简 (minimal)` / `紧凑 (compact)` / `速率优先 (speed)` / `HUD (hud)` / `详细 (detailed)` / `自由勾选 (custom)`。
   - **底栏 10 项字段芯片开关**（点击任意芯片自动切入 `custom` 模式并持久化）：
     `showContext`（上下文）、`showProgressBar`（字符进度条）、`showSpeed`（输出速率）、`showModel`（模型名）、`showCost`（会话费用）、`showTools`（运行中工具）、`showDuration`（会话时长）、`showTodos`（待办进度）、`showAgents`（子代理数）、`showGitBranch`（Git 分支）。
   - **底栏辅助格式**：上下文格式（`percent` / `tokens` / `both`）、分隔符（`dot` `·` / `pipe` `│`）、单击底栏动作（`openDashboard` 打开侧边栏 / `openDashboardTab` 打开编辑器宽屏标签页 / `switchSession` 快速切换会话）、无活跃对话自动隐藏开关（`hideWhenInactive`）。
   - **悬浮窗 9 大区块芯片开关**（`statusBar.tooltipSections`）：
     `context`（上下文与费用）、`speed`（输出速率）、`modelBranch`（模型与分支）、`activityDur`（时长与活动）、`tokens`（输入/输出/缓存明细）、`todos`（待办摘要）、`agents`（协作代理与后台任务）、`quota`（5h 订阅配额）、`actions`（底部快捷命令栏）。
2. **任务与环境配置区**：
   - 官方 `Task` 工具集成拨动开关（`claudeHub.todoTools.enabled`）及生效状态说明。
   - 快捷按钮组：`打开 Claude settings.json`、`打开 AGENTS.md`、`打开 CLAUDE.md`、`打开 VS Code 插件设置`。

## 5. 右下角状态栏与悬浮窗配置契约

### 5.1 新增与扩展的 `package.json` 配置项（向后兼容）

保留全部既有 `claudeHub.statusBar.*` 配置键与默认值，新增以下配置键：

| 配置键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `claudeHub.statusBar.style` | `"modern" \| "classic"` | `"modern"` | 同时控制状态栏图标风格与悬浮窗版式（`modern` 为 Speedometer 表格对齐与纯 Codicon，`classic` 为 0.2 经典 Claude Hub 风格） |
| `claudeHub.statusBar.preset` | 枚举扩展 | `"compact"` | 在原有 5 档基础上新增 `"speed"`（速率优先：`58.4 tok/s · Opus 5.5`） |
| `claudeHub.statusBar.clickAction` | 枚举扩展 | `"openDashboard"` | 新增 `"openDashboardTab"`（直接打开编辑器宽屏标签页） |
| `claudeHub.statusBar.separator` | `"dot" \| "pipe"` | `"dot"` | 自定义/紧凑连接符：` · ` 或 ` │ ` |
| `claudeHub.statusBar.showContext` | `boolean` | `true` | `custom` 模式下是否显示上下文数值 |
| `claudeHub.statusBar.showSpeed` | `boolean` | `true` | 非 `minimal` 模式下是否显示 `tok/s` 输出速率 |
| `claudeHub.statusBar.showDuration` | `boolean` | `false` | `custom` 模式下是否显示当前会话时长 |
| `claudeHub.statusBar.showAgents` | `boolean` | `false` | `custom` 模式下是否显示协作子代理计数 |
| `claudeHub.statusBar.tooltipSections` | `object` | 全部 9 项为 `true` | 控制悬浮窗中 9 个独立信息区块的显隐 |

同时升级命令面板中的 `claudeHub.configureStatusBar`：支持一键切换 `Modern / Classic` 风格、选择 6 档预设，或直接跳转到侧边栏「设置」Tab 的可视化定制器。

### 5.2 `Modern` vs `Classic` 渲染规则

- **`modern` 悬浮窗**：
  - 使用单行无边框 `<table width="100%"><tbody><tr>...</tr></tbody></table>` 与 `\n\n---\n\n` 分隔线，仅使用 VS Code DOMPurify 允许的 `color:var(--vscode-descriptionForeground);` 与 `color:var(--vscode-charts-blue);` 内联样式，避免出现默认表格斑马纹。
  - 所有图标使用 `$(sparkle)`、`$(sync~spin)`、`$(git-branch)`、`$(layout-sidebar-left)`、`$(link-external)`、`$(refresh)`、`$(arrow-swap)`、`$(settings-gear)` 主题图标。
  - 当用户在 `tooltipSections` 中关闭某区块时，自动省略对应行与多余的 `---` 分隔线；三列网格根据剩余可见列自动收敛为 1～3 列，不留空列。
- **`classic` 悬浮窗**：
  - 完整保留 `0.2.26` 的紧凑段落式 Claude Hub 版式（字符进度条 `▰▰▰▱▱▱▱▱`、⏱️/⚡/📋 视觉符号与动作链接），并同样接入 `tooltipSections` 的 9 项显隐控制，以及在底部动作栏补充 `[编辑器打开]` 入口。

## 6. 安全性、国际化与测试验收标准

1. **Webview 与悬浮窗安全**：
   - 所有来自本地 JSONL 会话标题、分支名、工具参数、模型名、记忆描述的字符串，在拼入 Webview DOM 与 Tooltip HTML `<table>` 前一律经过 `escHtml()` 转义，严禁未转义拼接。
   - `MarkdownString.isTrusted` 采用显式命令白名单 `{ enabledCommands: [...] }`，仅放行本扩展注册的安全命令。
2. **国际化对齐**：
   - `src/i18n.ts` 的 `en` 与 `zh-CN` 字典同步新增四分栏、状态栏定制器与新悬浮窗键名；`package.nls.json` 与 `package.nls.zh-cn.json` 同步新增命令与配置项文案，确保现有 i18n 对称性单测 100% 通过。
3. **自动化回归测试（`test/parser.test.ts`）**：
   - `formatStatusBarText` 单测：覆盖 `modern / classic` 两种风格、`minimal / compact / speed / hud / detailed / custom` 六种预设、`dot / pipe` 分隔符及 10 项字段开关组合。
   - `buildStatusTooltipMarkup` 单测：覆盖 `modern` 无边框表格输出、`classic` 经典输出、HTML 特殊字符转义、以及 `tooltipSections` 逐项关闭后的干净退化（无连续空分隔线）。
   - `getWebviewContent` 契约单测：覆盖四分栏 DOM、窄栏/宽栏样式类、协作代理防溢出样式规则、设置页自定义芯片控件，以及既有待办/Loop/Auto Memory/MCP 消息契约。
   - 全量校验：`npm test` 与 `npm run compile` 零错误通过，`scripts/package.ps1` 可正常打出 `0.3.0` VSIX。
